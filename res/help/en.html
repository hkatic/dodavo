Using this help

This help opens in your web browser, in the language Dodavo is using. To open it again, press F1 in any Dodavo window, or choose View Help from the Help menu.

Each topic is a level 2 heading. With a screen reader you can move from topic to topic with heading navigation (for example, the H key in browse mode in NVDA and JAWS, or in scan mode in Narrator). The contents list at the top links to every topic.

Names of menus, buttons and other controls are written exactly as they appear in Dodavo. Every task can be done with the keyboard alone; the keys are given in each topic and collected in Keyboard shortcuts.

How Dodavo works

Every computer running Dodavo has a Contact ID: a code of 64 characters made of the digits 0–9 and the letters a–f. The Contact ID works like a phone number for Dodavo. To send files to someone, you need their Contact ID; to receive files, you give your Contact ID to the people who will send them. Your Contact ID stays the same until you change it yourself; see Changing your Contact ID.

  1. You copy your Contact ID and send it to the other person, for example by email or in a chat message.
  2. The other person adds you to their recipient list, and you add them to yours.
  3. To send something, you select the person in your recipient list and choose a file or a folder.
  4. The other person is asked whether to accept the transfer and where to save it.
  5. The file goes directly from your computer to theirs, end-to-end encrypted.

Dodavo has to be running on both computers. When you close its window, Dodavo keeps running in the notification area so that it can receive files (you can change this in Settings).

Folders are packed automatically, sent as one item and unpacked again on the other computer; the other person can also keep them as a ZIP file (see When the transfer is complete). You don't have to create a ZIP file yourself. Files and folders keep their dates (see Are the dates of files and folders kept?).

Installing and uninstalling

Dodavo is installed with a setup program named Dodavo-version-setup.exe. Setup is a standard Windows wizard: Tab moves between the controls on a page, Space selects or clears a check box, Enter goes to the next page, Alt+B goes back a page, and Esc cancels. Screen readers read the title and text of each page when it opens. Setup uses your Windows display language; if Dodavo is not available in it, Setup first asks you to choose a language.

System requirements

Dodavo runs on Windows 7 with Service Pack 1, Windows 8.1, Windows 10 and Windows 11, both 32-bit and 64-bit (on ARM computers through the emulation built into Windows). Setup installs the right version for your Windows by itself. On Windows 7 without the Windows updates from 2019 for SHA-2 signatures, Windows cannot check the signature of the setup program and reports an unknown publisher.

Windows may warn you before the setup program starts. Windows 8.1, 10 and 11 show the SmartScreen message that Windows protected your PC: choose the link with more information and then the button that runs the program anyway. Windows 7 asks whether you want to run software whose publisher could not be verified: choose Run. Download the setup program only from the Dodavo page on GitHub. To check that your copy is the original, compare its SHA-256 checksum with the one published next to it: open a command prompt and run certutil -hashfile Dodavo-version-setup.exe SHA256.

Dodavo carries its own list of trusted certificate authorities for its encrypted connections to the relay and address lookup servers, so it does not depend on the certificates installed in Windows. It connects even on a Windows 7 whose root certificates have never been updated.

Installing Dodavo

  1. Run the setup program, for example by opening it from your Downloads folder.
  2. Setup asks how to install. Install for me only (recommended) installs Dodavo just for you and does not need administrator rights. Install for all users installs it for everyone who uses the computer; Windows then asks for administrator permission. Choose one with the arrow keys and press Enter.
  3. On the Select Destination Location page you can change the folder Dodavo is installed in. The suggested folder is fine for most people; press Enter.
  4. On the Select Additional Tasks page, press Space if you also want Create a desktop shortcut, then press Enter.
  5. On the Ready to Install page, press Enter to choose Install. Installing takes only a few seconds.
  6. On the last page, Launch Dodavo is selected. Press Enter to choose Finish; Setup closes and Dodavo starts.

Dodavo is then in the Start menu: press the Windows key, type Dodavo and press Enter.

If Dodavo is running when you install or uninstall it, you don't need to exit it first: Setup closes it when you choose Install, and the uninstaller after you confirm. Transfers that are running continue the next time Dodavo starts.

Updating Dodavo

Dodavo updates itself. Once a day, shortly after it has started and is online, it asks the Dodavo page on GitHub whether a newer version has been published. When there is one, a notification Update available appears and the Update Available window opens in the background; selecting the notification, or Alt+Tab, brings it to the front. The window says which version is available and which one you have; screen readers usually read this sentence when the window comes to the front. Then come, in Tab order:

Release notes (Alt+R)
A read-only text field with what is new. The focus starts here, so that you can read it before you choose. Read it with the arrow keys; Tab and Shift+Tab move between the text and the buttons, and from the last button back to the text.
Install Update (Alt+I; it is the default button, so Enter chooses it too)
Downloads the new setup program and installs it, as described below.
Remind Me Later (Alt+L, or Esc)
Closes the window. Dodavo reminds you again a day later; until then you can still install the update from the Help menu.

When you choose Install Update, Dodavo first asks what to do with transfers that are still running, with the same three choices as when exiting: Don't exit, Exit and continue the transfers later and Cancel the transfers and exit. Then it downloads the setup program; a line in the window shows the progress, and the focus moves to Cancel Download (Alt+C), which stops the download after a confirmation. The downloaded file is accepted only if its size, its checksum and its digital signature match what the Dodavo authors published; otherwise an error message says so and nothing is installed. Then Setup starts: the line in the window says so, screen readers usually read it aloud, and the focus returns to the release notes. If Dodavo is installed for all users, Windows first asks for administrator permission. As soon as Setup is ready, Dodavo closes, Setup installs the new version silently in the same place and with the same choice between “for me only” and “for all users”, and Dodavo starts again by itself with the notification Dodavo was updated. Your settings, your recipient list and your Contact ID are kept, and interrupted transfers continue as after any other restart. If you run Dodavo with several profiles, the other profiles are closed as well and have to be started again by hand.

To check at any time, choose Check for Updates… from the Help menu. When there is nothing new, a message says that you have the latest version; when the check fails, for example without an internet connection, the message says why. To stop the daily check, clear Check for updates automatically (once a day) in the settings; checks you start from the Help menu still work. You can also update by hand at any time: run the setup program of the new version from the Dodavo page on GitHub. It replaces the program in the same place and keeps your settings, your recipient list and your Contact ID.

Uninstalling Dodavo

  1. Open Windows Settings (Windows+I) and go to Apps, then Installed apps (on Windows 10: Apps & features). On Windows 7 and 8.1, open Control Panel and choose Programs and Features.
  2. Type Dodavo in the search box to find it in the list. In Windows 11, press Tab to reach its More options button, press Enter and choose Uninstall. In Windows 10, 8.1 and 7, select Dodavo in the list and choose Uninstall.
  3. Confirm with Uninstall and then Yes.

Uninstalling removes the program, its shortcuts, its entries in File Explorer's menus and the Start with Windows entry. Your settings, your recipient list and your Contact ID stay in the folder described in Your settings and identity, so if you install Dodavo again, everything is as before. Unfinished transfers stay as well, and continue if you install Dodavo again; otherwise you can delete their partly received files, which end in .part. If you want to remove them as well, delete that folder after uninstalling; your Contact ID is then lost for good.

Getting started

  1. Start Dodavo. Its main window opens with your recipient list, which is empty at first.
  2. Check your name: press Ctrl+Comma, or open the File menu (Alt+F) and choose Settings…. The first field, Your name (shown to the people you send files to), is filled in with your Windows user name. Change it if you like, then press Enter to save.
  3. Share your Contact ID: choose Copy My Contact ID from the File menu, activate the Copy My Contact ID button, or press Ctrl+Shift+C. Dodavo copies the ID to the clipboard and shows it in a message. Paste it into an email or chat message to the people who should be able to send you files.
  4. Add the people you want to send files to, as described in Adding a recipient.

Note: Your Contact ID is not secret. Anyone who has it can offer you files, but only the people in your recipient list can start a transfer without asking you, because Start transfers automatically, without asking is on (you can turn it off in Settings). An offer from anyone else always opens the Incoming Transfer window first, and nothing is saved until you accept it.

The main window

The main window contains, in Tab order:

Recipient list (Alt+R)
The people you can send files to. It has three columns: Name, Contact ID and Transfer. The Contact ID is shortened to its first eight and last six characters. While a transfer with a person is running, the Transfer column says what is happening, for example Sending – “report.pdf” (45%) or Waiting for the connection – “report.pdf” (45%), refreshed about once a second; with several transfers, it says how many are in progress. Otherwise it is empty. Move through the list with the arrow keys. Enter or a double-click opens the menu of actions for the selected person (see below). When the list is empty, it says so and tells you how to add someone.
Send File… and Send Folder… buttons (Ctrl+O and Ctrl+Shift+O)
Send something to the selected person.
Add Recipient… button (Ctrl+N)
Adds a new person to the list.
Copy My Contact ID button (Ctrl+Shift+C)
Copies your own Contact ID to the clipboard.

The buttons have no underlined letters, because in the main window Alt + a letter opens a menu. Use the shortcut keys in parentheses instead: they work wherever the focus is in the main window, and the File menu shows them next to its commands.

At the bottom of the window, a status line tells you whether Dodavo is connected:

  • Connecting to the network… while Dodavo starts.
  • Online – ready to send and receive files.
  • Offline – check your internet connection. Transfers within your local network still work.

The status line cannot receive keyboard focus. To hear it, use your screen reader's command for reading the whole window: NVDA+B in NVDA, Insert+B in JAWS, or Narrator+W in Narrator.

The menu bar has three menus. The File menu (Alt+F) contains Send File…, Send Folder…, Add Recipient…, Edit Recipient…, Remove Recipient, Block Recipient, Copy My Contact ID, Change My Contact ID…, Settings… and Exit. The Transfers menu (Alt+T) lists every transfer in progress, with the person, the item and the state, and ends with Show All Transfers (Ctrl+T); when nothing is running, it says No transfers in progress. See Finding a transfer that runs in the background. The Help menu (Alt+H) contains View Help, How It Works (a short summary), License (see License), Donate (see Donating), Check for Updates… (see Updating Dodavo) and About (the version, the author, the website and the license; see About Dodavo).

When a person is selected in the list, the menu of actions (Enter, a double-click, Shift+F10 or the Menu key, or a right-click) offers Send File…, Send Folder…, Show Transfer (only while a transfer with that person is running; Show Transfers when there are several), Edit…, Remove and Block.

Managing recipients

Adding a recipient

  1. Ask the person to choose Copy My Contact ID in their copy of Dodavo and send you the code.
  2. Press Ctrl+N, or activate the Add Recipient… button. The Add Recipient dialog opens.
  3. In Name (only used so you can recognize the person), type a name. Only you see this name.
  4. Press Tab and paste the code into Contact ID with Ctrl+V.
  5. Press Enter or activate OK.

Dodavo checks what you entered. If something is wrong, a message explains it and you stay in the dialog to correct it:

  • The name is empty, or another recipient already has that name.
  • The code is not a valid Contact ID (it must be exactly 64 characters, digits 0–9 and letters a–f). Make sure you copied all of it.
  • The code is your own Contact ID.
  • The Contact ID already belongs to another recipient.

The list is sorted alphabetically by name, and the new person is selected.

The list Largest item this person can send me sets how large an item the person can send you; see Limiting the size of what you receive.

Editing or removing a recipient

Select the person in the list, then:

  • To change the name or the Contact ID, press F2 or choose Edit Recipient… from the File menu. The Edit Recipient dialog works like Add Recipient.
  • To remove the person, press Delete or choose Remove Recipient from the File menu, then confirm with Yes.
  • To block the person, press Ctrl+B, or choose Block Recipient from the File menu, or Block from the menu of actions, then confirm with Yes. See Blocking a sender.

Sending files and folders

The other person must have Dodavo running. They don't need to have you in their recipient list, but if you are not in it, they will see a warning that the sender is unknown.

Sending a file

  1. Select the person in the recipient list.
  2. Press Ctrl+O, or activate the Send File… button. A standard Windows Open dialog appears.
  3. Choose the file and press Enter. To send several at once, select them first: Shift and the arrow keys for items next to each other, or Ctrl and the arrow keys to move and Ctrl+Space to select. Each one is sent as a separate transfer.

A progress window opens and the transfer starts. See Following a transfer.

You can also press Enter on the person, or double-click them, and choose Send File… from the menu that opens.

Sending a folder

  1. Select the person in the recipient list.
  2. Press Ctrl+Shift+O, or activate the Send Folder… button.
  3. Choose the folder and activate Select Folder. You can select several in the same way as files.

Dodavo first packs the folder, with all its subfolders, and then sends it. The other computer unpacks it again, so the person receives an ordinary folder, unless they chose in their settings to keep it as a ZIP file.

Dragging items onto a person

You can drag files and folders from File Explorer and drop them onto a person in the recipient list. If you drop several items at once, Dodavo asks you to confirm; each item is then sent as a separate transfer with its own progress window.

You can start as many transfers as you like at the same time, to the same person or to different people.

Sending to several people

To send the same items to several people at once, check their boxes in the recipient list: move to each person with the arrow keys and press Space, or click the box before the name. Then send a file or a folder as usual, or drop the items onto one of the checked people. Dodavo sends to everyone who is checked, and to the selected person when nobody is checked. The window in which you choose the files names the recipients in its title, and after a drop Dodavo asks you to confirm them.

Every person gets a transfer of their own for each item, with its own progress window, so one person can decline or be away while the others receive the item. Once the transfers have started, the boxes are cleared. Dropping items onto a person who is not checked sends to that person only. Editing, removing and blocking apply to the selected person, whoever is checked. The Send with Dodavo window has the same boxes: see Sending from File Explorer.

Sending from File Explorer

You can send files and folders directly from File Explorer, also when Dodavo is not running:

  1. Select one or more files or folders in File Explorer.
  2. Press Shift+F10 to open the context menu, or right-click the selection. On Windows 11, right-clicking first shows a shorter menu: choose Show more options there. Shift+F10 opens the full menu right away.
  3. Choose Send with Dodavo (W), or choose Send to and then Dodavo.
  4. The Send with Dodavo window opens. It says how many items you selected, and the focus is on the Recipients list. Choose the person with the arrow keys and press Enter, or activate Send. To send to several people, check each of them with Space first; the items then go to everyone who is checked.

Each item is sent as a separate transfer with its own progress window. Nothing is sent before you choose Send; Esc or Cancel closes the window without sending anything. To read what you selected, press Alt+I and use the arrow keys in the Items field. If you have no recipients yet, the window says so and the focus is on Add Recipient… (Alt+A). Items you send to Dodavo while the window is open are added to it.

The context menu offers Send with Dodavo for up to 100 selected items. For more, use Send to, or send the folder they are in. You can remove both entries with Add Dodavo to File Explorer's menus in Settings.

When a sent item has arrived

When the other person has received everything, the checksum has been confirmed and the item has been saved on the other computer, Dodavo shows a message, for example Done! Ana has received the file., followed by the name of the item. Screen readers read it. Press Enter or Esc, or choose Close; the progress window closes too.

If you select Don't show this again, the progress window closes by itself next time, and a notification tells you that the transfer is complete. You can turn the message back on in Settings with After sending, show a message once the item has arrived. If the progress window is hidden or minimized when the transfer ends, or other transfers with the same person are still running, there is only the notification. A transfer that fails, is declined or is cancelled keeps its progress window open, so that you can read what happened. With Close the progress window when a transfer ends selected in Settings, that window closes as well, there is no message, and the notification says how the transfer ended.

Receiving files and folders

When someone sends you something, Dodavo shows a notification, Incoming transfer, and opens the Incoming Transfer window in front of other windows. If Windows keeps the window in the background, its taskbar button flashes; press Alt+Tab to reach it.

The Incoming Transfer window

The window starts with a bold line saying who wants to send you a file or a folder, followed by the name and size of the item. For a folder, it also says how many files it contains. Then come:

Unknown sender warning
Only shown when the sender is not in your recipient list. It shows the sender's shortened Contact ID and reminds you to accept files only from people you know. The name in the window is the name the sender gave themselves, so it cannot prove who they are. A check box, Add “…” to my recipients, lets you add the sender to your list when you accept.
Save to: (Alt+S)
The folder the item will be saved in. With Always save received files to this folder on in Settings, it is the folder from that option, which is your Downloads folder unless you chose another one. With that option off, it is the folder you used last time, or your Downloads folder. You can type a different folder, or use Browse… (Alt+B) to choose one.
Free disk space
A sentence below the folder says whether there is enough free space on that drive, how much is needed and how much is available. A folder that is unpacked needs room both for the download and for unpacking; a folder that you keep only as a ZIP file needs room for the ZIP file (see After receiving a folder in Settings). The sentence is updated when you choose a folder with Browse or leave the folder field. On a drive with the FAT32 file system, such as many USB sticks and memory cards, no file can be 4 GB or larger: if the transfer would save such a file there, the sentence says so, and you need to choose a folder on another drive.
Accept (Alt+A) and Decline (Alt+D)
When the window opens, the focus is on Accept, so pressing Enter accepts; screen readers usually read the text of the window first, from the bold line to the free disk space sentence. Pressing Esc or closing the window declines.
Block Sender (Alt+K)
Declines what the person sends and blocks them, after you confirm with Yes. See Blocking a sender.

If an item is larger than a size limit you set, a line under its name and size says so. You can still accept it. See Limiting the size of what you receive.

When one person sends several items at once, they share one window, and your answer applies to all of them. The bold line says how many there are, the next line gives their total size, and the Items field (Alt+I) lists them. Items that arrive while the window is open are added to it, and those that arrived within the last second are not covered by your answer yet: they stay in the window.

If there is not enough free space, Dodavo asks whether you want to accept anyway. If the sender cancels before you answer, the window closes and a notification tells you so.

After you accept, a progress window shows the transfer. If an item with the same name already exists in the folder, the new one is saved with a number added, for example Report (2).pdf; nothing is overwritten.

When the transfer is complete

A received file gets its real name and the dates it had on the sender's computer. A received folder is unpacked into the chosen folder, unless you chose otherwise in Settings under After receiving a folder: with Keep only the ZIP file (don't unpack), Dodavo saves it as a ZIP file, for example Photos.zip, and with Keep both the unpacked folder and the ZIP file, it saves the folder and the ZIP file next to each other, for example Photos and Photos.zip.

Then Dodavo asks what you want to do with what you received:

  • For a file: Open the file opens it in its default program, and Open the folder opens File Explorer with the file selected.
  • For a folder: Open the folder opens it in File Explorer.
  • For a folder kept only as a ZIP file, the message says Done! The folder has been saved as a ZIP file., and you have the same choices as for a file.
  • Close does neither.

If you select Don't ask me again, Dodavo shows a notification instead next time. Selecting the notification shows the item in File Explorer. You can turn the question back on in Settings with After receiving, ask whether to open the file or folder. While other transfers with the same person are still running, Dodavo does not ask, and shows the notification instead; the question comes after the last one. With Close the progress window when a transfer ends selected in Settings, Dodavo does not ask either.

Receiving without being asked

Transfers from people in your recipient list start immediately, without the Incoming Transfer window, as long as Always save received files to this folder and Start transfers automatically, without asking are both on in Settings. They are on unless you clear them. Dodavo shows a notification, Receiving, and saves the item in the folder from the first option, which is your Downloads folder unless you chose another one. Transfers from unknown senders, transfers that would not fit on the disk and items larger than a limit you set never start this way. Only the people you added yourself can start a transfer this way: their Contact ID cannot be forged.

To choose where to save each item, clear Always save received files to this folder: every transfer then opens the Incoming Transfer window. To decide about every transfer but keep your folder as the suggestion, clear Start transfers automatically, without asking instead.

Blocking a sender

If someone sends you things you do not want, you can block them. Dodavo then declines everything they send you, without asking and without a notification. They see only that their offer was declined, and are not told that they are blocked. Transfers with them that are already under way go on; cancel them in their progress windows if you want them to stop.

  • In the Incoming Transfer window, activate Block Sender (Alt+K) and confirm with Yes. Everything the person offers that waits for an answer is declined.
  • In the main window, select the person and press Ctrl+B, or choose Block Recipient from the File menu or Block from the menu of actions. A blocked person is removed from your recipients.

To unblock someone, open Settings, activate Blocked Senders… (Alt+E), select the person in the Blocked Senders dialog and activate Unblock (Alt+U). Adding a blocked person as a recipient also unblocks them.

Limiting the size of what you receive

You can set the largest size of an item that someone can send you, so that nobody fills your disk, by mistake or on purpose. Open Settings, select Limit the size of an item that someone can send me (Alt+Z), type a whole number in Largest size (Alt+G) and choose MB or GB in the list after it. The limit applies to each item by itself: a file by its size, and a folder by its size packed or unpacked, whichever is larger. It applies to everyone, also to senders who are not in your recipient list.

The list When an item is over the limit (Alt+H) decides what happens to a larger item:

  • Ask me before it starts: the item never starts by itself. The Incoming Transfer window opens, says that the item is larger than the limit you set, and you can still accept it. This is the choice unless you change it.
  • Decline it without telling me: Dodavo declines the item at once and shows nothing.
  • Decline it and tell me: Dodavo declines the item at once, and a notification, Item declined, tells you who offered what.

When Dodavo declines an item, the sender sees only that the offer was declined, not why. A recipient can have a limit of their own, which comes before the one in Settings: in the Add Recipient or Edit Recipient dialog, choose Any size or This size: in the list Largest item this person can send me (Alt+L); with This size:, type the size in the field after the list and choose its unit. As set in Settings is the choice for a new recipient. A changed limit applies to what is offered from then on.

Following a transfer

Every transfer, sent or received, has its own progress window. Its title says what is happening, for example “Sending file to Ana”. The window shows:

  • A bold line with the person and the name of the item.
  • The current step: Packing the folder…, Connecting to …, Waiting for … to accept…, Sending…, Receiving…, Checking the data already transferred…, Unpacking the folder… or, when you send a folder, … is unpacking the folder…. While a transfer is paused or the connection is lost, the step line says so (see below).
  • A progress bar.
  • Transferred: (or Processed: while a folder is packed or unpacked) with the amount done, the total and the percentage.
  • Speed: and Time remaining:, updated once a second while data is being transferred or processed. When no data has been transferred for a few seconds, the speed is shown as zero.
  • The type of connection: Connection: direct (computer to computer) or Connection: through a relay server (end-to-end encrypted). This line is empty while there is no connection.
  • Three buttons: Pause (Alt+P), which becomes Resume (Alt+R) while the transfer is paused; Minimize to background (Alt+B), which hides the window and lets the transfer continue (see Finding a transfer that runs in the background); and Cancel, which asks for confirmation before it cancels the transfer.

When the window opens, the focus is on Minimize to background; Pause becomes available once the data is flowing. Tab moves between the buttons, and Enter activates the focused one. The other lines cannot receive the focus, but screen readers usually read them all when the window comes to the front, for example when you switch to it with Alt+Tab. To hear the progress again later, use your screen reader's command for reading the whole window: NVDA+B in NVDA, Insert+B in JAWS, or Narrator+W in Narrator.

When the transfer ends, the step line says how it ended, for example Done! Ana has received the file. or The transfer was cancelled. If something went wrong, the line below gives the reason. The Cancel button becomes Close. When you have received an item, the progress window closes by itself once the item is saved (see When the transfer is complete); when you have sent one, Dodavo tells you with a message and then closes the window (see When a sent item has arrived).

You can cancel a transfer until the very end, also while a received folder is being unpacked; Dodavo then removes what it had unpacked. Only at the last moment, when the received item is already getting its name, is it too late: the item is saved, and the progress window says so as usual. When you send an item, only the other person can cancel it once all the data has arrived and has been checked: from then on, Cancel is unavailable, the step line says so (for example All of it has arrived, so the transfer can no longer be cancelled. Waiting for Ana to confirm that it is saved…), and closing the progress window lets the transfer continue in the background. If the focus was on Cancel, it moves to Minimize to background, and, unless the transfer is complete a moment later, a notification, All of it has arrived, says why. While they unpack a folder you sent, a notification, Unpacking on the other side, says so; the transfer is complete once the folder is unpacked. If you cancel just as the last data goes out, the step line says Cancelling… until the other computer has said whether everything arrived; if it did, it was too late to cancel, and a notification, Too late to cancel, says so. The cancel is not lost if Dodavo is closed before the answer comes: the next time it starts, the notification Unfinished transfer says that the transfer is still being cancelled, and Dodavo waits for the answer again, also if the transfer was paused.

Pausing and resuming

Activate Pause (Alt+P) to stop the transfer for a while; the step line says Paused. Select Resume to continue. and the button becomes Resume (Alt+R). Either side can pause, whether sending or receiving. The other person sees that the transfer was paused on your side, and a notification tells them. When you resume, the transfer goes on exactly where it stopped: nothing is sent twice and nothing is lost, and the checksum at the end covers the whole item.

A paused transfer stays paused until you resume it, even if the connection is lost in the meantime or Dodavo is restarted. You can still cancel it.

When the connection is lost

If the internet connection drops, one of the computers goes to sleep, or Dodavo is closed on either side, the transfer is not lost. The step line says The connection was lost. The transfer continues as soon as you are both online again, even after a restart. Dodavo keeps what has already arrived and continues from that point when the two computers can reach each other again – after a few seconds, or days later.

If the connection stays lost for a few seconds, Dodavo shows a notification, Connection lost, and the transfer waits. It continues by itself, so you don't need to do anything. You can change this in Settings, under If the connection is lost during a transfer:

  • Wait for the connection and continue does what is described above. It is the default.
  • Ask every time makes Dodavo ask after a few seconds. Wait for the connection leaves the transfer waiting, and Cancel the transfer ends it. Select Don't ask me again to always do the same.
  • Cancel the transfer cancels the transfer after a few seconds, without asking. Partly received data is deleted.

When Dodavo starts, it picks up the transfers that were interrupted last time: a notification, Unfinished transfer, appears for each of them, and its progress window opens without taking the focus. A transfer that cannot continue gets the notification Transfer not completed instead, and its progress window says why, for example Nothing happened in the transfer for more than 30 days. Before the data continues to flow, the step line says Checking the data already transferred… while Dodavo verifies what it already has. A transfer picked up this way simply waits for the other side; it does not ask whether to wait or to cancel. While data is flowing, Dodavo also keeps the computer from going to sleep by itself.

Closing a progress window during a transfer

If you close a progress window (with Esc, Alt+F4 or the window's Close button) while the transfer is still running, Dodavo asks what to do:

  • Continue in the background hides the window (the same as the Minimize to background button). The transfer goes on, and a notification tells you when it is finished. Finding a transfer that runs in the background explains how to bring the window back.
  • Cancel the transfer stops it after you confirm, and the window disappears. If it was too late to cancel because the item was already being saved, a notification, Too late to cancel, tells you that it has been saved.

Select Don't ask me again to always do the same. You can change the choice later in Settings, under When closing the window of a running transfer. When an item you send has already arrived in full, so that the transfer can no longer be cancelled, Dodavo does not ask: the window is hidden and the transfer continues in the background. Nor does it ask once you have cancelled the transfer and the cancel waits for the other computer's answer: the window disappears until the transfer has ended.

Finding a transfer that runs in the background

A transfer whose window is hidden goes on as before. You can bring its window back at any time:

  • Open the Transfers menu (Alt+T) in the main window. It lists every transfer in progress, for example Ana: Sending – “report.pdf” (45%); choose one to show its window. Show All Transfers (Ctrl+T) shows them all. When nothing is running, the menu says No transfers in progress, and Ctrl+T tells you the same.
  • In the recipient list, the Transfer column shows the state next to the person. Open the person's menu of actions (Enter) and choose Show Transfer (or Show Transfers when there are several).
  • The menu of the notification area icon has the same Transfers submenu, so you can get to a transfer even while the main window is closed.
  • Selecting a Windows notification about the transfer also brings its window back.

Once the window is visible again, it behaves as if it had never been hidden: when the transfer ends, it asks the usual questions instead of only showing a notification.

Chatting with a person

You can exchange short text messages with a person, for example to say what you are about to send or to ask about something you were offered. Messages go directly from one computer to the other, encrypted, over the same kind of connection as files. Both of you have to be running Dodavo and be online at the same moment, and the Dodavo on the other side has to have chat too.

Opening a chat

  • In the main window, select the person and press Ctrl+M, or choose Chat with Recipient… from the File menu, or Chat… from the person's menu of actions (Enter).
  • In the Incoming Transfer window and in a progress window, activate Chat (Alt+C) to write to the person the transfer is with.
  • When someone writes to you, their chat window opens by itself. It does not take the focus from what you are doing.

There is one chat window for each person. Its title is Chat with followed by the person's name, and the focus starts in the Message field.

Writing to several people at once

To send the same message to several people, check their boxes in the recipient list (Space) and press Ctrl+M, or choose Chat with Recipient… from the File menu. Instead of a chat, the Message to Several People window opens: it names the recipients, and has a Message field and the buttons Send (Enter) and Cancel (Esc). Each person gets the message as a private message from you. They do not see who else got it, and each answer arrives in the chat with that person. The message is added to your conversation with each of them, and the boxes are cleared once it was sent. If it cannot be delivered to one of them, a notification says so, and that conversation marks it as not sent. With one box checked, Ctrl+M opens the chat with that person.

The chat window

The controls, in Tab order:

History (Alt+H)
A list with one message per item, the newest last. Each item says who wrote the message, when, and the text, for example Ana, 14:32: The photos are on their way. or You, 14:33: Thanks!. A message from another day also has its date. Use the Up arrow and Down arrow keys to read the messages, Home and End for the first and the last one, and Ctrl+C to copy the selected message. When you move to the list, the newest message is selected.
The status line
One line below the history that shows the message that arrived last, that the other person is typing, or why a message was not sent. It cannot receive the keyboard focus; screen readers read it when it changes and when the window comes to the front.
Message (Alt+M)
Where you write. A message can have up to 4000 characters.
Send (Alt+S or Enter)
Sends the message and adds it to the history. The focus stays in the Message field.
Add to My Recipients (Alt+A)
Only for a person who is not in your recipient list: opens the Add Recipient window with their name and Contact ID filled in.
Block (Alt+B)
Blocks the person after you confirm, and closes the chat. A blocked person can neither write to you nor send you anything.
Delete Conversation… (Alt+D)
Deletes the messages with this person from your computer after you confirm. The default answer is No.
Close (Esc)
Closes the window. The conversation is kept, and is there again when you open the chat.

When a message arrives

  • While the chat window is in front, the message is added to the history and shown in the status line, where screen readers read it out, with the name of the person first.
  • While you are in another window, the chat window opens or stays where it is without taking the focus, its taskbar button flashes, and a notification, Message from with the person's name, shows the message. Screen readers usually read notifications. Selecting the notification brings the chat to the front.
  • A sound plays in both cases, unless you turned it off.

When the other person starts writing, the status line says so, for example Ana is typing…. While the chat window is in front, this is announced once, with a short sound; it is not repeated while they go on writing. The other person is told in the same way when you write. Both can be turned off in Settings.

When a message cannot be sent

A message that cannot be delivered is marked in the history, for example You, 14:35 (not sent): Are you there?, the status line says why, and a sound plays. Dodavo does not try again by itself. The text is put back into the Message field if that is empty, so that you can press Enter to send it again. The reasons you may see:

  • The other computer could not be found on the network or Connection attempt timed out: Dodavo is not running on the other computer, or one of you is offline.
  • This person does not accept messages from you: the other person takes messages only from their recipients, or has blocked you.
  • Dodavo on the other side does not have chat: the other person has a Dodavo without chat.
  • The connection was lost or The other side did not confirm the message: the connection ended before the message was confirmed.

Who can write to you

Unless you change it, anyone who has your Contact ID and is not blocked can write to you, as anyone can offer you a file. A chat with a person who is not in your recipient list shows a warning with their Contact ID above the history. In Settings, on the Chat tab, you can choose Only my recipients: messages from anyone else are then refused without you seeing them, and their sender is told that you do not accept messages from them.

Where conversations are kept

Conversations are kept on your computer, with your settings, until you delete them: the newest 2000 messages with each person. They are not sent anywhere else. Delete Conversation… in a chat window deletes one, and Delete All Conversations… in Settings, on the Chat tab, deletes all of them. Deleting removes the messages from your computer only; the other person keeps their copy.

Running in the notification area

When you close the main window, Dodavo keeps running in the notification area at the end of the taskbar, so that it can receive files. The first time this happens, a notification explains it.

  • To show the main window again, start Dodavo again (for example, from the Start menu), or select its notification area icon. Starting Dodavo again does not start a second copy: the one that is running brings its window to the front.
  • To reach the icon with the keyboard, press Windows+B, then use the arrow keys to move to Dodavo. If it is not there, it may be among the hidden icons: select the Show hidden icons button first. Press Enter to open the window, or Shift+F10 or the Menu key for the icon's menu.
  • The icon's menu contains Open, Transfers (a submenu with the transfers in progress, see Finding a transfer that runs in the background), Copy My Contact ID and Exit.
  • While transfers run, the icon shows their number in a small badge, and its tooltip (what a screen reader reads when you move to the icon) says what is going on, refreshed about once a second: for example Dodavo – Sending – “report.pdf” (45%), 12.3 MB/s, or Dodavo – 2 transfers in progress, 45%, 12.3 MB/s when there are several.

To quit Dodavo completely, choose Exit from the File menu or from the icon's menu. If transfers are still running, Dodavo asks first and offers three choices: Don't exit (the default, so Enter or Esc keeps Dodavo running), Exit and continue the transfers later (they are interrupted and continue the next time Dodavo and the other computer are both running) and Cancel the transfers and exit. When you sign out of Windows or shut it down, Dodavo does not ask; the transfers continue the next time. After exiting, you can no longer receive files until you start Dodavo again.

Dodavo reports finished transfers, incoming transfers, pauses by the other side, lost and restored connections, available updates and other events with Windows notifications, also while a progress window is minimized to the background. Screen readers usually announce them. Selecting a notification about a transfer brings its window to the front. If you miss one, or if Do not disturb is on, you can find it in the Windows notification center (Windows+N in Windows 11).

Connections and security

Dodavo connects computers with iroh, using Contact IDs instead of IP addresses. You don't need to set up your router or firewall.

Direct connection
Usually the two computers connect directly, even when both are behind a home router.
Local network
Computers on the same network find each other there, so they can exchange files even without an internet connection.
Relay server
When a direct connection is not possible, for example on strict company networks, the data goes through a public relay server. It stays end-to-end encrypted, so the relay cannot read it. The progress window tells you which kind of connection is used.
Encryption and integrity
All transfers are end-to-end encrypted. Every transfer is also checked with a checksum, so a damaged file is never saved as if it were complete. A file being received is first written with the extension .part and gets its real name only when it is complete; if the connection is lost, the .part file is kept until the transfer continues; if the transfer fails or is cancelled, the incomplete data is removed.
Folders
Dodavo refuses to unpack a received folder that contains unsafe paths, such as paths that would write outside the destination folder.
Received files are marked as coming from another computer
Like a web browser with downloads, Dodavo marks every file it receives (also the files in a received folder, and a kept ZIP file) as coming from the internet. Windows SmartScreen therefore checks a received program before it runs, and Microsoft Office opens received documents in Protected View. The mark is stored with the file on NTFS drives; drives formatted with FAT32 or exFAT, such as many USB sticks, cannot keep it. See Troubleshooting if Windows warns about a file you trust.

Your settings and identity

Dodavo stores its settings, your recipient list and your secret key in the folder %APPDATA%\Dodavo. The secret key is what makes your Contact ID yours. Don't share the contents of this folder. If you move to another computer and want to keep your Contact ID, copy this folder to the same place on the new computer while Dodavo is not running there. If the folder is deleted, Dodavo creates a new Contact ID, and everyone has to add you again. To get a new Contact ID on purpose, see Changing your Contact ID.

Frequently asked questions

What is the advantage of Dodavo over social networks, messaging apps and cloud services?

With Dodavo, the file goes from your computer straight to the other person's. Nothing is uploaded to a server, so nothing is stored, scanned or kept by a third party, and there is no account to create, no storage quota and no link that expires. Files arrive exactly as they are: photos and videos are not shrunk or recompressed, and there is no size limit. Every transfer is end-to-end encrypted, and computers on the same network exchange files even without an internet connection.

The trade-off is that Dodavo must be running on both computers when a transfer starts. If one side goes away afterwards, the transfer waits and continues later; see What happens to a transfer if something interrupts it?

How does a transfer work?

You select a person in your recipient list and choose a file or a folder. Dodavo looks up the other computer by its Contact ID and connects to it, directly if possible or through a relay server otherwise. The other person sees the name and size of the item and chooses Accept and a folder to save it in, or Decline. The data then streams, encrypted, from your computer to theirs, and both sides show a progress window. At the end, the received data is checked against a checksum; only then does the file get its real name. See How Dodavo works and Following a transfer.

How are folders sent and received?

A folder is sent as one item. Dodavo first packs it, with all its subfolders, into a temporary ZIP archive in the folder for temporary files (%TEMP%\Dodavo, unless you chose another one in Settings), or next to the folder, as a hidden file, when that drive has too little free space and the folder is on another drive that has enough; the progress window says Packing the folder…. The archive is sent, and the other computer saves it in the chosen folder, as name.zip.part, and then unpacks it there (Unpacking the folder…). The person receives an ordinary folder with the same name; if a folder with that name already exists, a number is added. The temporary archives are deleted afterwards. The receiving computer therefore needs free space for both the archive and the unpacked folder, on the drive of the chosen folder. (Only an archive of 4 GB or more for a drive with the FAT32 file system, which cannot hold it, is kept in the temporary folder.) If the person keeps the ZIP file (After receiving a folder in Settings), the archive is not deleted and gets the name name.zip at the end; with Keep both the unpacked folder and the ZIP file, the ZIP file gets its name as soon as it has arrived and been checked, and Dodavo then unpacks it into a folder next to it with the matching name (for example Photos (2) next to Photos (2).zip). If unpacking fails or is cancelled, Dodavo removes the partly unpacked folder (and, when both are kept, the ZIP file too). If Dodavo is closed while it is unpacking a folder, it unpacks the folder again the next time it starts: it first deletes the incomplete folder, and the new one gets the same name. A received archive that contains unsafe paths, such as paths pointing outside the destination folder, is refused. See Sending a folder.

Are the dates of files and folders kept?

Yes. A received file, and every file and folder in a received folder, gets the Date modified and the Date created it had on the sender's computer. Only the date it was last opened (Date accessed) is new.

Hidden files and folders in a received folder stay hidden. Other attributes, such as read-only, are not kept.

A ZIP file normally stores just one date per item, in the local time of the computer that made it and only to two seconds; a different time zone or a change to daylight saving time can shift it by an hour or more. That is why Dodavo also stores the exact dates in its ZIP files, in the same extra field that 7-Zip writes, and uses them when it unpacks a folder. If you keep the ZIP file and unpack it later with another program, that program decides which dates it restores. File Explorer, for example, may give the unpacked files a new Date modified when the ZIP file is marked as coming from another computer, as received files are (see Connections and security); a program such as 7-Zip keeps the dates.

What happens to a transfer if something interrupts it?

Once a transfer has been accepted, Dodavo remembers it on both computers and continues it where it stopped, as soon as both are running and can reach each other again. Nothing is sent twice, and the checksum at the end still covers the whole item. What happens in each case:

You close Dodavo by mistake, or choose Exit
Dodavo asks first. Don't exit is the default, so pressing Enter or Esc keeps it running. Exit and continue the transfers later stops the transfer for now; it continues the next time Dodavo runs on both computers.
Dodavo stops unexpectedly, or is ended in Task Manager
Nothing is asked and nothing is lost. The next time Dodavo starts, the transfer appears again, Dodavo checks the data it already has (Checking the data already transferred…) and goes on from there.
The computer is shut down or restarted
The same. Dodavo does not hold up the shutdown; it lets the other side know that it is going away for now. Start Dodavo again after the restart (or turn on Start with Windows in Settings) and the transfer continues by itself. Even after a power cut, Dodavo continues from the last point it had safely written to disk, because it writes the received data to disk regularly.
The computer goes to sleep
While data is flowing, Dodavo keeps the computer from going to sleep by itself, as a download does (the screen may still turn off). If the computer is put to sleep anyway, or the lid is closed, the transfer stops and continues when the computer wakes up.
The internet connection drops
The progress window says The connection was lost. The transfer continues as soon as you are both online again, even after a restart. After a few seconds, Dodavo shows a notification and the transfer waits, unless you chose something else in Settings. Computers on the same home or office network keep transferring without the internet.
Any of this happens on the other person's computer
Your window says that the connection was lost, or that the transfer was paused on the other side, and the Transfer column of your recipient list shows the same. You don't need to do anything: the transfer continues when the other side is back.
Another program is using the partly received file
A virus scanner, a backup or sync program, or a program in which you opened the .part file can keep Dodavo from writing to it, or, once all of it has arrived, from saving or unpacking it. The progress window on the receiving side then says Another program is using the partly received file. The transfer continues as soon as that program closes it., and Dodavo shows a notification; the Transfer column of the recipient list says Waiting for another program. Nothing is lost: the transfer waits and continues by itself as soon as the file is free, and Dodavo says so. On the sending side, the progress window and a notification say that another program on the other side is using the file, and the Transfer column says Waiting for a program on the other side. If it takes long, close the other program, or cancel the transfer.
When a transfer is not continued
Only when someone decides so, or when continuing is impossible: you or the other person chose Cancel the transfers and exit or Cancel the transfer, or Settings say Cancel the transfer when the connection is lost; the other person had not accepted the transfer yet; the file being sent was changed in the meantime; nothing happened for 30 days; or the partly received file was deleted. In these cases, simply send the item again.

See When the connection is lost and Running in the notification area.

Does the other person have to be online?

To start a transfer, yes: Dodavo must be running on both computers, otherwise you see Could not connect to …. Once a transfer has been accepted, either side may go offline, go to sleep or exit Dodavo; the transfer continues when both are back, as described in the previous answer.

Is there a size limit?

Not unless you set one. Dodavo itself has no limit on the size of a file or folder; the only limits are the free space on the receiving drive and, on a drive with the FAT32 file system (many USB sticks and memory cards), that no single file can be 4 GB or larger. For a folder, the receiving computer needs room for the archive and for the unpacked folder, so roughly twice the folder's size while unpacking (unless it keeps only the ZIP file). The Incoming Transfer window says whether there is enough space before you accept. To set the largest size of an item that others can send you, see Limiting the size of what you receive.

Can I send several items at once, or to several people?

Yes. You can start as many transfers as you like, to the same person or to different people, and each has its own progress window. To send several files or folders in one go, drag them from File Explorer onto the person in your recipient list; after you confirm, each item is sent as a separate transfer. See Dragging items onto a person. You can also select them in File Explorer and send them from there: see Sending from File Explorer. The Transfer column of the recipient list and the Transfers menu keep track of all of them. To send the same items to several people at once, see Sending to several people.

Where are received files saved?

In your Downloads folder, unless you chose another one in Settings under Always save received files to this folder. If you clear that option, Dodavo asks every time. Whenever the Incoming Transfer window opens, you can change the folder under Save to: for that transfer. If an item with the same name already exists there, the new one gets a number added to its name; nothing is ever overwritten. See The Incoming Transfer window and Receiving.

Does Dodavo work without an internet connection?

Yes, between computers on the same local network, for example at home or in an office. They find each other on the network directly. The status line then says Offline – check your internet connection. Transfers within your local network still work., and transfers to computers elsewhere wait until you are online again.

Can anyone read my files on the way?

No. Every transfer is end-to-end encrypted between the two computers. When the data has to go through a relay server, the relay only passes on encrypted data that it cannot read. The Contact ID is the recipient's public key, so the connection can only be established with the computer that holds the matching secret key. See Connections and security.

Is my Contact ID secret? Can anyone send me files?

The Contact ID is not secret; it works like a phone number. Anyone who has it can offer you a file. Only transfers from people in your recipient list start by themselves (Start transfers automatically, without asking, which you can turn off in Settings). From anyone else, nothing is saved on your computer until you choose Accept, and their offers are marked with an unknown sender warning. See Receiving without being asked. If someone keeps sending you things you do not want, see Blocking a sender. To stop everyone who has your Contact ID at once, see Changing your Contact ID.

What does Dodavo send to servers on the internet?

Only what is needed for other computers to find yours. Dodavo publishes the addresses at which your computer can currently be reached under your Contact ID, to the lookup service of the iroh network, and keeps a connection to a relay server so that a transfer can be set up even when a direct connection is not possible. The names and contents of your files travel only inside the encrypted connection to the other computer. Once a day, when Check for updates automatically (once a day) is on, Dodavo also fetches from the Dodavo page on GitHub (github.com) a small file that describes the latest version, and it downloads the setup program from there when you choose to install an update; see Updating Dodavo. Dodavo has no accounts and sends no usage statistics.

How do I know that a received file is intact?

Every transfer ends with a checksum over the whole item, which the receiving side verifies. While a file is being received, it has the extension .part; it gets its real name only after the checksum has been confirmed. Data that does not match is never saved as a complete file: the transfer reports The received data is damaged (checksum mismatch), and the sender simply sends the item again.

Why does the Incoming Transfer window warn about an unknown sender?

Because the sender's Contact ID is not in your recipient list. The name shown in the window is the name the sender chose for themselves, so it cannot prove who they are. Accept the transfer only if you know who is sending it, for example because the person told you. The check box Add “…” to my recipients adds the sender to your list when you accept, so the next transfer from them is no longer marked. See The Incoming Transfer window.

Why does the progress window say the connection goes through a relay server, and is that slower?

Dodavo always tries to connect the two computers directly. When that is not possible, for example behind a strict company firewall or on some mobile networks, the data goes through a relay server instead. The transfer stays end-to-end encrypted, but it is usually slower, because the relay's bandwidth is shared. You don't have to do anything: Dodavo keeps looking for a direct path during the transfer and switches to it when one appears. If relayed transfers are common for you, try another network or connect the computer by cable.

Why is a transfer slow?

A transfer is only as fast as the slowest part of the path between the two computers. For most home connections that is the sender's upload speed, which is much lower than the download speed in the advertisements: an upload of 20 megabits per second moves about 2 megabytes per second, so a 2 GB file takes about a quarter of an hour. Wi-Fi quality, other downloads and video calls, and sending to several people at once (they share your upload) slow it down further. Dodavo adds no limit of its own.

When the two computers are connected directly, the data goes through no server, and other Dodavo users have no effect on your speed at all. When a direct connection is not possible, for example behind a strict firewall or on some mobile networks, the data goes through a free public relay server instead. That relay is shared by everyone who uses Dodavo and by other programs built on the same network, and its capacity is limited, so at busy times relayed transfers get slower. The connection line in the progress window tells you which case you are in: Connection: direct (computer to computer) or Connection: through a relay server (end-to-end encrypted). A network cable instead of Wi-Fi, the same local network, or simply trying again later usually helps. See Why does the progress window say the connection goes through a relay server, and is that slower?

Do I need to open ports or change my router or firewall?

No. Dodavo connects through home routers and firewalls by itself, without port forwarding. If Windows Defender Firewall asks whether to allow Dodavo the first time it starts, allow it; otherwise direct connections may be impossible and transfers go through a relay server.

Does Dodavo work on Windows 7?

Yes. Dodavo runs on Windows 7 with Service Pack 1 and on Windows 8.1, 32-bit and 64-bit; the setup program installs the right version by itself. A few things look different there: notifications appear as small balloons next to the clock and there is no notification center, so a notification you miss is gone (the Transfers menu and the Transfer column still show what is going on); and without the Windows updates from 2019, Windows reports the setup program as coming from an unknown publisher. Encrypted connections work even on a Windows 7 that has never been updated, and transfers continue after interruptions in the same way as on newer Windows. See System requirements.

Something went wrong. What should I check?

First make sure that Dodavo is running on both computers and that the status line in both main windows says Online – ready to send and receive files., and that you have the right Contact ID for the other person. If a transfer has ended with an error, the line below the step line in its progress window gives the reason; the Troubleshooting topic explains the messages. A transfer can always be cancelled and started again.

Troubleshooting

“Could not connect to …”
Dodavo is not running on the other computer, or one of you is offline. Ask the other person to start Dodavo and check the status line at the bottom of both main windows, then try again. Also check that you have the right Contact ID for them.
“The file was changed after the transfer started”
The file you are sending was modified while the transfer was waiting for the connection, so it cannot be continued. Send it again.
“The recipient reported that the transfer failed on the other computer” or “The sender reported that the transfer failed on the other computer”
Dodavo on the other computer could not go on with the transfer, or no longer knows it: the item being sent was changed or deleted, the partly received data is gone, it was closed before the transfer was accepted, or more than 30 days have passed. The progress window on the other computer says what happened there. Ask the sender to send the item again.
The transfer says the connection was lost, but we are both online
Wait a moment: Dodavo tries again every few seconds. If Dodavo was restarted on either side, make sure it is running on both. You can always cancel the transfer and start it again.
The status line says Offline
Check your internet connection. Transfers to computers on your local network still work.
“This is not a valid Contact ID.”
Part of the code is missing or has extra characters. Ask the person to choose Copy My Contact ID and send it again, then paste the whole code.
The other person never sees my transfer
Check that Dodavo is running on their computer; it may be in the notification area. Their Incoming Transfer window may be behind other windows; they can reach it with Alt+Tab.
“Not enough free disk space”
Choose a folder on another drive with Browse…, or free up space and try again. Remember that folders need room for the download and for unpacking.
Windows or Microsoft Office warns when I open a received file
Dodavo marks received files as coming from another computer, as browsers do with downloads (see Connections and security). If you trust the sender, choose Enable Editing in Office, or open the file's properties in File Explorer (Alt+Enter) and select Unblock on the General tab.
“The received data is damaged (checksum mismatch)”
The data was changed on the way, and the item was not saved. Ask the sender to send it again.
“The clipboard is in use by another program.”
Wait a moment and try copying your Contact ID again.
“The update information is not signed by the Dodavo authors, so it is ignored.”
The file that describes the latest version was changed on its way to you, or it was not made by the Dodavo authors. Nothing is installed. Try again later; if it keeps happening, download the setup program by hand from the Dodavo page on GitHub and compare its checksum with the published one.
“Setup ended before the update was installed”
Setup was closed right after it started, usually because the request for administrator permission was declined (an installation for all users needs it). Choose Check for Updates… from the Help menu and try again.
Dodavo did not start again after an update
Start it from the Start menu. If the message “The update to Dodavo … was not installed” appears, Setup did not finish; run Check for Updates… again, or install the new version by hand.
Other Dodavo profiles were closed by the update
An update closes every running copy of Dodavo and starts only the one that installed it again. Start the other profiles by hand; their transfers continue.
Dodavo does not start a second time
Only one copy of Dodavo runs at a time. Starting it again brings the existing window to the front.
